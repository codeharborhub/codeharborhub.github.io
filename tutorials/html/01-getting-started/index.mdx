Welcome to the very first module of the **CodeHarborHub HTML Tutorial**! 🎉

Every website you have ever visited, from a simple blog to a huge social network, is built on **HTML** (HyperText Markup Language). It is the skeleton of the web, and learning it is the first step of every frontend and full-stack developer's journey.

In this module you will go from *"What even is HTML?"* to *building and inspecting your very own web page*, step by step, with no prior experience required.

:::tip No experience? No problem!
This module is written for absolute beginners. All you need is a computer, a web browser, and curiosity.
:::

## What You Will Learn

By the end of this module, you will be able to:

- Explain **what HTML is** and what role it plays in a website.
- Understand the **history of HTML** and how it evolved into HTML5.
- Describe **how the web works**, from typing a URL to seeing a page.
- Read and write a valid **HTML document structure**.
- Create, save, and open your **first HTML page**.
- Use **browser developer tools** to inspect and debug any web page.

## A Quick Peek at HTML

Curious what HTML looks like? Here is a tiny, complete web page:

```html title="index.html"
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, CodeHarborHub! 👋</h1>
    <p>This is my very first web page.</p>
  </body>
</html>
```

## What You Need Before You Start

You don't need to install anything complicated. Here is the short checklist:

1. **A modern web browser**: [Google Chrome](https://www.google.com/chrome/), [Mozilla Firefox](https://www.mozilla.org/firefox/), or [Microsoft Edge](https://www.microsoft.com/edge).
2. **A code editor**: [Visual Studio Code](https://code.visualstudio.com/) is highly recommended and free.
3. **A folder** on your computer to save your practice files.

:::info
Even a basic text editor such as Notepad will work, but a code editor gives you syntax highlighting, auto-completion, and a much better experience.
:::

## Tips for Learning Effectively

- **Type the code yourself.** Copy-pasting feels fast, but typing builds muscle memory.
- **Experiment freely.** Change things, break things, and see what happens. That is how you learn.
- **Use the developer tools often.** They are your best friend for understanding any website.
- **Practice a little every day.** Consistency beats long, occasional study sessions.

:::warning Don't skip the fundamentals
It is tempting to jump straight to CSS and JavaScript, but a solid understanding of HTML makes everything that follows easier.
:::
