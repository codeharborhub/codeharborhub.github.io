Think of a newspaper or a textbook. Big titles tell you what the page is about, and smaller titles break it into sections. HTML **headings** do the same job on the web. They give your content a clear outline that people, search engines, and screen readers can all follow.

## What Is a Heading?

A heading is a short piece of text that names the content below it. HTML provides **six levels** of headings. `<h1>` is the most important and `<h6>` is the least important.

```html title="Syntax"
<h1>Heading level 1</h1>
<h2>Heading level 2</h2>
<h3>Heading level 3</h3>
<h4>Heading level 4</h4>
<h5>Heading level 5</h5>
<h6>Heading level 6</h6>
```

Each heading has an opening tag, the text, and a closing tag. The browser makes headings **bold** and gives them a default size, and it adds space above and below them.

## The Six Heading Levels

| Tag | Level | Typical use | Default size (approx.) |
| :-- | :-- | :-- | :-- |
| `<h1>` | 1 | The main title of the page | 2em (32px) |
| `<h2>` | 2 | Major sections | 1.5em (24px) |
| `<h3>` | 3 | Subsections of an `<h2>` | 1.17em (18.7px) |
| `<h4>` | 4 | Smaller subsections | 1em (16px) |
| `<h5>` | 5 | Fine-grained details | 0.83em (13.3px) |
| `<h6>` | 6 | The lowest level | 0.67em (10.7px) |

:::info
The sizes above are **browser defaults**. You can change them with CSS. The level tells the browser how **important** the heading is, not how big it should look.
:::

## Heading Hierarchy

Headings should form a tree, like the table of contents of a book. Each level nests inside the one above it.

```text title="A good outline"
h1  Web Development
├── h2  HTML
│   ├── h3  Text Content
│   └── h3  Links and Images
├── h2  CSS
│   ├── h3  Selectors
│   └── h3  Layout
└── h2  JavaScript
```

Here is the same outline written in HTML.

## Best Practices

### 1. Use one `<h1>` per page

The `<h1>` is the title of the whole page. A blog post, a product page, and a tutorial each get one `<h1>`.

### 2. Do not skip levels

Go from `<h2>` to `<h3>`, never from `<h2>` to `<h5>`. A missing level leaves a hole in the outline.

### 3. Choose by rank, not by size

If you want smaller text, use CSS. Do not pick `<h6>` just because it looks small.

### 4. Keep headings short and clear

A good heading tells the reader what comes next in a few words. Prefer "Install Node.js" over "Things you might want to do first".

:::tip Read your headings alone
Take away all the paragraphs and read only the headings. If the page still makes sense, your outline is good.
:::

## Common Mistakes

<Tabs>
<TabItem value="bad" label="Wrong" default>

```html
<h1>My Blog</h1>
<h4>Latest Posts</h4>      <!-- skipped h2 and h3 -->
<h1>About Me</h1>          <!-- a second h1 -->
<h3>Please subscribe!</h3> <!-- used only to get bigger text -->
```

</TabItem>
<TabItem value="good" label="Right">

```html
<h1>My Blog</h1>
<h2>Latest Posts</h2>
<h2>About Me</h2>
<p><strong>Please subscribe!</strong></p>
```

</TabItem>
</Tabs>

:::warning Do not fake headings
Wrapping text in `<b>` or `<span style="font-size: 2rem">` looks like a heading but is **not** one. Screen readers and search engines will not treat it as a heading.
:::

## Why Headings Matter

### SEO

Search engines read your headings to learn what each section is about. Clear headings that contain your topic words help your page rank for the right searches.

### Accessibility

Screen reader users often jump from heading to heading instead of reading the whole page. A correct outline is like a menu for them. Without it, the page is much harder to use.

### Readability

Headings break long text into pieces. Readers scan them to decide which part to read.

## Styling Headings with CSS

You control the look of headings with CSS while keeping the correct level in HTML.

    padding-bottom: 4px;
  }

## Headings vs the Title Tag

Beginners often mix up `<title>` and `<h1>`. They are different.

| Element | Where it appears | Purpose |
| :-- | :-- | :-- |
| `<title>` | Browser tab and search results | Names the page for browsers and search engines |
| `<h1>` | Inside the page content | Names the page for the reader |

They are often similar, but they do not have to match exactly.

## Practice

Try this in your editor.

1. Create a file called `recipe.html`.
2. Add an `<h1>` with the name of a dish.
3. Add two `<h2>` headings: **Ingredients** and **Steps**.
4. Under **Steps**, add an `<h3>` for each stage, such as **Prepare** and **Cook**.
5. Add a short `<p>` under every heading.
6. Read only the headings. Does the outline tell the story of the recipe?

## Key Takeaways

- HTML has six heading levels, `<h1>` (most important) to `<h6>` (least important).
- Headings build the **outline** of your page.
- Use one `<h1>` and never skip levels.
- Pick headings for **meaning**, and use CSS for **appearance**.
- Good headings help SEO, accessibility, and readability.
